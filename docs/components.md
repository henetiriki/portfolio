# Component Catalogue

All components are function components (except `ErrorBoundary`) written in TypeScript, styled with Mantine's CSS Modules + CSS variables (see [Styling & Theming](styling-theming.md)). Each feature folder exports through an `index.ts` barrel, imported via the `@components/*` alias.

## `content/` — page chrome

| Component         | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Header`          | Full-height hero title block used at the top of every content page (`<Title order={1}>` + a `<span>` sub-line)                                                                                                                                                                                                                                                                                                        |
| `Content`         | The repeated "card" section: a `WaveWrapper` top/bottom SVG divider around a semi-transparent (`valhalla`, 90% opacity) content box. `waveTop`/`waveBottom` props (both default `true`) let a page omit a divider, e.g. `/travel` hides the bottom wave on the intro `Content` and the top wave on the legend `Content` so the map sits flush between them.                                                           |
| `FixedBackground` | Full-viewport, fixed, `z-index: -1` background image using the current `igImgId` from state (see [State Management](state-management.md)) and `IMAGE_HOST`. It is the deliberate preloaded LCP image. Registers `pageTopRef` into global state on mount — this is the single source of truth for "top of page" used by both `Navigation`'s and `Footer`'s scroll-to-top. Loaded via `next/dynamic` with `ssr: false`. |
| `Transition`      | Full-screen dark overlay with a Mantine `Loader` (inheriting the theme's default `type='dots'`), shown while `useLoading()` reports a Next.js route change in progress.                                                                                                                                                                                                                                               |

**The home hero's "I'm a/an {role}" article agrees with whichever role is showing**, via `useArticleAgreement` (`@hooks`). The rotating role is typed in by `react-type-animation`, which exposes no callback for which sequence entry is current and no way to colour part of its own text — so the article has to stay outside the animated span, and the hook watches that span's rendered text with a `MutationObserver` rather than tracking the library's own randomised typing timings. It matches the leading letter, not the leading sound, which is fine for the current word list and would be wrong for a future "European" or "MBA"; that limitation is [open work](roadmap.md).

**Do not hand the hook's ref to the `next/dynamic` wrapper itself.** `next/dynamic` calls `useImperativeHandle` on the ref it is given and never forwards it to the wrapped component, so a ref aimed at `DynamicTypeAnimation` silently never reaches the real `<span>` — nothing errors, the observer simply never fires. The ref goes on a plain `<span>` wrapping the dynamic import instead; `MutationObserver`'s `subtree: true` still sees the descendant's text changes.

## `nav/`

| Component        | Responsibility                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Navigation`     | Sticky header with `Logo`, desktop inline menu (hidden below `sm`), a `Burger`-triggered mobile `Drawer`, and a semantic 44px `ActionIcon` scroll-to-top control with a visible focus ring. Its passive listener tracks only crossings of the 10px threshold; the background becomes opaque (`black-russian`) once scrolled or while the drawer is open. Both the desktop menu and the drawer menu are `<nav aria-label='Main'>` landmarks. They deliberately share one label because only one is ever in the accessibility tree — `Navigation.module.css` hides the other with `display: none`, which removes it entirely rather than merely hiding it visually. |
| `NavigationLink` | A single nav `Anchor` with an animated underline (`::before`) that's always-on for the active route (matched by exact `pathname` equality) and animates in on hover. `variant='sm'` gives the mobile drawer 24px text, 32px horizontal padding and a 64px target; underline transitions stop under reduced motion.                                                                                                                                                                                                                                                                                                                                                |

### `experience/VideoContainer`

Renders the optional YouTube embed for a timeline entry, inside a fixed-ratio box. The iframe is **`loading='lazy'` and that is load-bearing, not cosmetic**: the embed sits roughly 35,000px down a 39,000px page, and a bare `youtube.com/embed` frame costs about a megabyte of player JavaScript. Loading it eagerly put that execution on the main thread during initial page load — for content almost nobody scrolls to — and measurably hurt `/experience` in PageSpeed relative to every other route, including `/travel`, whose far heavier Google Map is deferred until it is in view. The explicit `width`/`height` reserve the box, so deferring costs no layout shift. Guarded by a unit test and by browser specs asserting the player is not requested on load but is once scrolled into view.

## `experience/` — timeline primitives (used only by `/experience`)

A set of small, single-purpose components composed together in `pages/experience.tsx` to lay out each job/school entry: `Timeline`, `TimelineBox`, `TimelineContent`, `TimelineFromTo` (renders the `year.from`–`year.to` range), `TimelineHeading` (section heading with an icon, e.g. `IconBriefcase`/`IconSchool`), `TimelineInstitution` (name + optional link), `TimelineLocation`, `TimelineTitle`, and `VideoContainer` (renders an embedded YouTube iframe when a job entry defines `video`).

Their horizontal spacing is viewport-dependent below the `xs` breakpoint: `TimelineBox`'s rail-to-card padding and `TimelineContent`'s own padding both narrow, as does the arrow `TimelineContent` draws outside its left edge, and `Timeline`'s margin moves the rail 7px nearer the screen edge (12px in the initial cut — see [D-260821a](decisions.md#d-260821a--give-the-mobile-icons-back-some-edge-clearance-and-a-colour-that-survives-contrast)). `TimelineHeading`'s icon also shrinks, 2.5rem to 2rem, below `xs`. Two relationships constrain any further change and are asserted by `experience-gutter.mobile.spec.ts` — `Timeline`'s margin is where `TimelineHeading`'s icon centre falls (the icon's own negative margin and the row's vertical alignment both carry the offset), and the arrow shares the rail-to-card gap with the dot. See [D-260816k](decisions.md#d-260816k--reclaim-the-timelines-gutter-from-the-container-not-from-the-rail).

## `travel/` — Google Maps feature

See [Travel Feature](travel-feature.md) for the full data/behaviour spec. Component summary:

| Component                                    | Role                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `MapWrapper`                                 | Top-level orchestrator: renders loading/error states while `useGoogleMaps()` loads the Maps libraries, delegates viewport-intersection tracking to `useIntersectedOnce` and layer-completion tracking to `useLayerCompletion` (both `@hooks`), then allows `Map` to reveal the current city only after all layers and rail loading have settled. Its `mapStatus === 'success'` branch is wrapped in its own `ErrorBoundary`, so a runtime crash inside the map's render tree also degrades to `MapError` instead of the whole page crashing.                                                                                                                                                                                                                                         |
| `Map`                                        | Owns the actual `google.maps.Map` instance, supplies the vector Map ID and other immutable/base `mapOptions()` at construction, applies responsive zoom separately, and performs a fixed-duration, fractional camera reveal to the current city once everything has loaded. Reduced motion jumps to the target; the animation frame cancels on cleanup.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `MapPlaceholder`                             | Blurred Maps Static API image `Map` overlays on `#map` until `tilesloaded`, faded out via `mapRendered`; see [Loading placeholder](travel-feature.md#loading-placeholder)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `Marker`                                     | One accessible `google.maps.marker.AdvancedMarkerElement` with a custom SVG child; imperatively drives CSS drop/bounce animation, click → InfoWindow and zoom-responsive DOM scaling, and cancels delayed work/listeners on cleanup. The InfoWindow uses Google's native close/focus behaviour plus timed auto-close.                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `Polyline`                                   | One `google.maps.Polyline`, built from either literal `legs` (city-to-city arrays) or encoded `paths` (rail trips); delayed drawing/listeners clean up on unmount and reduced motion draws immediately.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `Legend` / `MarkerLegend` / `PolylineLegend` | Static key explaining marker/line colours and solid-vs-dotted (past vs upcoming) trips; marker entries share the live markers' exact SVG path, theme colour and base scale                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `MapLoader` / `MapError`                     | Loading spinner / failure message selected by `useGoogleMaps()`; `MapLoader` is also used by `next/dynamic` while the client-only map bundle loads. `MapError` reuses `Map.module.css`'s `.mapContainer` class, so it occupies the same 65vh height and `black-russian` background the interactive map would, matches `Content`'s padding so its text lines up with the surrounding page copy, and includes a "Reload page" button — the map's own `ErrorBoundary` never resets `hasError` on its own, and `window.location.reload()` is the only recovery that reliably clears a Maps SDK left in a broken partial-init state (see [D-260825b](decisions.md#d-260825b--nest-errorboundary-inside-mantineprovider-scope-a-second-boundary-to-the-map-and-centre-the-root-fallback)). |
